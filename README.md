# Fallen Hero: Rebirth 简体中文汉化

《Fallen Hero: Rebirth》Steam 版非官方简体中文汉化项目。

## 当前状态

汉化补丁正在进行发布整理与最终测试。

本项目为免费、非商业性质的玩家本地化项目。
使用补丁需要自行拥有并安装正版《Fallen Hero: Rebirth》。

## 下载

正式版本发布后，请前往本仓库的 Releases 页面下载。

请勿从来源不明的第三方重新打包站点下载本补丁。

## 支持版本

具体支持的 Steam BuildID 及文件校验信息将在每个 Release 中注明。

## 安装

正式发布版本将附带自动安装与卸载脚本。

安装程序会验证玩家本机的正版游戏文件，仅对对应版本执行汉化。
